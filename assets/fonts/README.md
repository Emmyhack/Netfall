# Wordmark font

`archivo-wordmark.woff2` is Archivo (Omnibus-Type), licensed under the SIL
Open Font License 1.1, instanced at width 112 / weight 700 and subset to the
letters of the wordmark: N, a, e, f, l, t. The full licence text is in
`OFL.txt` and the font's own name table retains the copyright and licence
records.

Regenerate by fetching the `Archivo:wdth,wght@112,700` static instance from
Google Fonts and subsetting with fontTools (`populate(text='Netfall')`,
`name_IDs=['*']`, flavor woff2).
